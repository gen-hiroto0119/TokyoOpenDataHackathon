## 何が入っていないか

### 都庁まで辿れない

**網の西端は経度 139.6966 で、都庁（139.6917）の 442m 手前で終わっている。** 目的地までの直線距離は次のとおり。

| 目的地 | 最寄り出口 | 直線距離 |
|---|---|---|
| 歌舞伎町 | 11番出入口 | 164m |
| バスタ新宿 | 新宿駅 3番出入口 | 283m |
| 東京都庁 | 京王 新宿駅 7番出入口 | 470m |
| 新宿中央公園 | 京王 新宿駅 7番出入口 | 649m |

しかも**都庁へは新宿駅西口から地下道が直結している**。実際には地上に出ずに行ける。7番出入口は京王新宿駅の地下から地上へ上がる階段で、都庁へ向かう人が使う出口とは限らない。

### 出口は 22 件しかない

新宿駅の出口は実際にはもっと多い。このデータで街に出る出口として使えるのは、番号付きの出入口 22 件だけ。

**「口」を含む地物 36 件を調べたが、番号付き以外はすべて改札だった**（JR西口、京王線 京王西口、丸ノ内線 西口改札口など）。JR の西口や南口は、このデータでは「改札」であって「出口」ではない。改札の先も modelled な屋内空間として続く。

**行き止まりノード 742 件は出口ではない。** 中身は設備で、階段 57、エレベーター 27、ATM 22、コインロッカー 20、エスカレーター 19、トイレ 24。網が設備ごとに枝を伸ばしているだけ。ここを出口候補にすると全部間違える。

### ホームから改札まで計算できない

歩行網のノードは通路・階段・EV・改札まわりが主。JR・小田急の番線名はあるが、対応ジオメトリにナビノードが付いていない。京王・丸ノ内のホーム名は見当たらない。**改札より内側は計算できない。**

### 営業時間はほぼ無い

時間帯を持つ地物は 15,556 件中 **12 件**。契約は `asOf` で時間帯を絞れるようにしているが、実データではほとんど効かない。

### 名前が入っていないもの

`RESEARCH.md` のとおり、西武新宿、バスタ新宿、都営新宿線、都庁はエンティティ名に出てこない。

## ここから決めること

**評価 4「集合後の目的地へ進みやすい」がデータで支えられていない。** いま出している「出口まで 637m」は、構内グラフ上の距離としては正しいが、都庁へ向かう人が実際に通る道とは違う。このまま出すと嘘になる。

打てる手は 3 つ。

**1. 出口案内をやめる。** 責務を「改札から集合場所まで」に絞る。評価 4 を落とし、`onward` を返さない。契約と画面から `Handoff` が消える。データが支えられる範囲だけを出す形になり、いちばん正直。ただし README の「その後の目的地にも進みやすい」が中心価値から外れる。

**2. 屋外の歩行データを足す。** [新宿駅西部の歩行空間ネットワーク](https://catalog.data.metro.tokyo.lg.jp/dataset/t000029d0000000007)（デジタルサービス局、2020年10月、更新予定なし）は西口から都庁方面の屋外を含む。構内グラフとは別系統なので、繋ぎ目を手で作る必要がある。繋げば評価 4 が本当に計算できる。

**3. 主要な目的地だけ手で結ぶ。** 都庁へは地下道の入口を「都庁への出口」として登録する。代表ケースは通るが、他の目的地には効かない。
